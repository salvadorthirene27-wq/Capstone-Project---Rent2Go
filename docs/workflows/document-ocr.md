# Private document text assistance

Booking identity and applicable driver-license uploads can use OCR.Space for optional readable-text extraction. The original file, expiry declaration, immutable submission and agency document decision remain separate. Extracting text, comparing it or recording an unusable result never approves identity, reserves a resource, changes booking status or creates money movements. Manual document review remains available without OCR.

## Commands and states

| Action | Authorized actor and conditions | Saved outcome |
| --- | --- | --- |
| EXTRACT | Renter explicitly permits the exact stored file; an active independent agency operator may use an existing renter permission after submission. Current pending file, valid saved bytes and source stage are required. | Immutable command, permission when applicable, one unfinished job and a separately saved terminal result. |
| REVOKE | Original renter identifies the current permission. | Append-only permission withdrawal; unfinished job cancelled. Future dispatch is blocked. Existing saved history is retained. |
| COMPARE | Current independent agency operator identifies the latest exact successful/partial result and pending submitted document; acknowledgement is explicit. | Immutable comparison, either compared with original or needs manual assessment. A separate document decision is still required. |
| CLOSE_STALLED | Current permitted document participant acknowledges that the database deadline has passed. | The unfinished job closes as UNKNOWN, not success. A new extraction requires a fresh explicit request. |

Results distinguish success, partial text, failure/manual fallback, cancellation and unknown interrupted outcome. A stopped or failed result does not imply that the provider never received the earlier request. Jobs have a two-minute recovery deadline and a ten-attempt lifetime limit per document; no automatic provider retries occur. Identical command/content retries return saved state, while changed retries fail.

## Consent, privacy and processing

The client cannot nominate an arbitrary URL, upload bytes through the OCR endpoint, choose another renter or supply a provider credential. Only the already private server-owned file is loaded. Its size, SHA256 and supported file signature are checked. Agency access excludes unsubmitted replacements; Super Admin and Cosigner roles do not implicitly gain private renter-document access. Current source access, agency/member/actor state, cancellation and exact permission are checked under booking/authority locks before dispatch and again before retaining the result. Stored audit metadata contains identifiers/status, never extracted text, provider errors or keys.

The reservation transaction commits before object loading or the provider call. No database lock is held across the external HTTP request. If the source, permission or actor access changes, late output is discarded. Withdrawing permission stops future submissions but cannot recall bytes already dispatched. Consent and extraction history are retained alongside the private document, and this is disclosed before requesting extraction. An agency comparison identifies the exact immutable result digest and cannot overwrite it or act as renter consent.

The server uses the fixed HTTPS OCR.Space endpoint, a header credential, a generic filename, a45-second timeout and a bounded response. The conservative free-service limits are1MB input and at most3 returned pages. Text is bounded to20,000 full Unicode characters and marked partial if clipped; PDF page coverage is not independently verified, so the original must always be inspected. Returned links, overlays, raw provider errors and searchable PDFs are not exposed or fetched. Text renders as plain text. Current API details were checked against https://ocr.space/ocrapi on7 November2026. Provider settings remain server-side; the real key belongs only in ignored .env.local.

## Interface

Each document has a lazy optional text-assistance disclosure. Opening it reads saved state; it does not submit the document to OCR. The renter names the provider in explicit permission; agencies see the existing renter permission and their independent comparison responsibility. Status refresh, bounded unfinished-job recovery, saved history, original-document comparison links and permission withdrawal are available according to current rights. Failed actions preserve an identical retry; a source refresh resets checked permission. Request abort/generation guards prevent late output overwriting another document. Access-denied refreshes clear previously displayed private output. The existing requirements acceptance/correction controls remain the authoritative human review.
